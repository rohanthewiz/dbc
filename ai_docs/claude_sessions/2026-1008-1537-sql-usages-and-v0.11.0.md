## Ask

1. "do N-165": fix the SQL editor's Shift+F12 for an alias used once.
2. `/sw` (sess-wrap) and a minor version bump. Asked how to ship it, the
   user chose the full CI release (the `release` branch: tests, tag,
   goreleaser, a GitHub Release) over a tag-only one.

## Decisions

- **Widen the action, don't add a second one.** Script tabs already had
  `dbc.goToUsages` (Shift+F12 and the right-click "Go to Usages",
  `editor.action.referenceSearch.trigger`). Its precondition went from
  `dbcScript` to `editorHasReferenceProvider`, so one action covers both
  editors. Its keybinding wins over Monaco's own Shift+F12 wherever a
  provider exists. Monaco's Go to References (the jumping one) is still in
  its menu for anyone who wants it.
- **Minor, not patch.** v0.10.0 → v0.11.0. The features since v0.10.0 are
  new (routines in the sidebar, Postgres in Docker, rerun ↻, Go to
  Definition/Usages in scripts), not fixes.
- **CI path.** The release commit hand-edits `version/version.go`, so
  `release.yml` uses 0.11.0 as-is instead of bumping the patch. It is NOT
  `[skip ci]`, because a `[skip ci]` head commit would stop the release
  workflow too. `release` fast-forwards to main (`origin/release` was
  v0.8.0's commit, an ancestor of main). The workflow tags; no local tag is
  made.
