## Server

- **Saved tabs** (`web/store.go`): `Tab.Script` and a `tabs.script` column,
  added with `ALTER TABLE … ADD COLUMN IF NOT EXISTS`. `saveTab` refuses a
  script name `ValidScriptName` would refuse (400). A script tab boots
  without a `consoleDb`.
- **Several `s.Show`s** (`workspace`):
  - `scriptRes` keeps the newest `MaxScriptResults` (20) results of a
    script run, and `scriptCut` counts the ones dropped.
  - `ScriptResults() (n, at, cut)` reports them. `ShowScriptResult(i)`
    makes result i the LastResult, so the grid, copies, exports and the
    assistant all follow. It is refused while busy or out of range.
  - A new script run starts a new list. A straggling show from an old run
    is ignored. A query's own result clears the list.
- **Web** (`web/hub.go`, `api.go`, `scripts.go`):
  - `resultSets {n, at, cut}`, sent only when there are two or more, rides
    on the "result" event, the script's "run" event and `wsState.sets`.
  - `POST /api/v1/ws/:id/show-result {i}` returns `{sets, status}`.

## Page

- **`web/static/js/scripts.js`** (new, `dbc.scripts.create(host)`, the
  pattern tabgroups.js uses):
  - The file store. Save is the console protocol:
    - A conflict loads the file's text as one undoable edit.
    - `{conflict, rev: ""}` means the file was deleted or trashed: the tab
      keeps its text, marked unsaved.
    - A 409 on `base ""` (made elsewhere meanwhile) loads that file as a
      conflict.
  - Drafts live in localStorage as `dbc.script.draft.<name>` =
    `{base, text}`. A draft typed against an older revision keeps that
    base, so the first save meets the conflict instead of overwriting.
  - The check runs 600 ms after typing stops and turns its diags into
    markers. ✓ Check also logs them. The check runs again once Monaco
    loads.
  - The browser:
    - Sections for Scripts, the templates (when the dir is empty),
      Examples and Trash (folded).
    - Keys: Enter runs, Shift+Enter edits, F2 renames, Ctrl/⌘+Delete
      trashes, Alt+N opens New. They are chords, not the plan's bare
      E/N/Del, because the filter keeps the focus.
    - Hover buttons ▶ ✎ ⋯, ⧉ Copy, + New and ↺ Restore.
  - Go completion and hover from `/api/v1/script-api`. Without types, it
    reads the text:
    - `<recv>.` uses Run's own name for `*sdb.S`.
    - `sdb.` lists the package's funcs and types.
    - A variable takes its call's first result type (`firstResult`) or the
      sdb type it was declared as.
    - Composite-literal fields.
    - Connection names inside a `connArgs` string.
- **app.js "script tabs"**:
  - A tab with `script` uses doc key `s:<name>`, and its title is the
    name. One tab per script.
  - It never connects: `applyScriptState` draws it instead. The Tables
    pane shows a note. A connection click inserts `"name"`, and Connect
    from the Connections menu is refused with a pointer to a query tab.
  - `.script-mode` hides Run all, Explain, the rows box and ERD, and shows
    ✓ Check and ⤓ Save. The header reads `▷ name.go ● · 1 error`.
  - Run saves first and stops if the save does not land.
  - Ctrl+S saves the script. In a query tab it flushes the console and the
    tab.
  - A double-click renames the script. Closing a tab with unsaved changes
    asks: save, discard or keep.
  - Script tabs have their own right-click menu, and the keys help has a
    "Script tabs" group.
  - `drawSets` draws "Result 1 · 2 · 3" on the results bar.
- **editor.js**:
  - Documents can have a fixed language (`useDoc(key, text, "go")`). Go
    models indent with tabs, and `setDriver` and the statement marker skip
    them.
  - New: `isScript`, `setMarkers`, `ready(fn)`, Ctrl+S → `dbc.cmd.save`.
  - A `dbcScript` context key turns off Ctrl+X/⇧X/Alt+X explain in a
    script tab.
- **The rest**:
  - grid.js: a script tab's empty-grid hint.
  - Workbench: the `#check-btn`, `#save-btn` and `#rsets` elements, and
    `scripts.js` in the script list.
  - CSS for all of the above.
- **Monaco**: `scripts/vendor_monaco.sh` keeps `basic-languages/go/go.js`
  (3.4 KB). Re-vendoring changed nothing else.

## N-110 fixed

- Captured right before the reload, the console file was empty in every
  run, passing ones included. Those passed only because `release` saves
  the shown console on pagehide.
- The cause: `saveTab(active)` cleared the debounced `saveTimer`, which
  also carried `saveConsole`. A rename within 600 ms of typing dropped the
  console save.
- `saveTab` now also saves the active tab's console.
- "tabs survive a reload" checks the console file before reloading. With
  the fix reverted, it fails there.
