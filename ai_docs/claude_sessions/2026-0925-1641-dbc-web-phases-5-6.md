## Found and fixed in the browser runs

- Monaco disposes a model it made itself (`value:`) on `setModel`, so the
  first tab's document died on the first switch — the first model is now
  created explicitly.
- Monaco's word highlighter rejected an unheld promise on every model
  switch ("Uncaught (in promise) Canceled") — `occurrencesHighlight: "off"`.
- A double-click on a background tab started a rename that the tab's
  activation redrew away — the strip is not redrawn under an open rename.
- Narrow screens: the topbar's actions did not wrap once ▷ Scripts and
  ✦ Assistant were added (420 px scrolled sideways).
