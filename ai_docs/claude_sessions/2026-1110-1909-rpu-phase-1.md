## What changed

23 commits on `main` (`3ff4eab` … `9330b69`). Each item's closing line in
`ai_docs/todo/next-list.md` has the detail; in short:

**The splitter and its neighbours (sqlsplit)**

- **N-247** — comments per engine: `Dialect.commentAt` is the one place the
  scanner, Lex, Verbs, HasKeyword and the formatter ask. `#` is a comment
  on MySQL only; only Postgres (and Generic) nest `/* */` — bytdb does not,
  against the plan's text; MySQL's `/*!…*/` and MariaDB's `/*M!…*/` are
  opaque code. `--` stays a comment on MySQL whatever follows (a misread
  can only merge, never cut). hl.js mirrors it. Also fixed: a `#`-headed
  SELECT on MySQL ran as an Exec and lost its rows.
- **N-306** (raised and closed here) — dollar quotes only on Postgres and
  Generic, never where a `$` continues a name (`a$b$c`); the formatter's
  words run through `$`. Done first: `DELIMITER $$` needs it.
- **N-248** — `sqlsplit/body.go`: a statement's head decides whether a `;`
  inside it holds — BEGIN/CASE … END blocks after CREATE
  TRIGGER|PROCEDURE|FUNCTION|EVENT (Postgres BEGIN ATOMIC included), parens
  after CREATE RULE — and MySQL's client `DELIMITER` works. The formatter
  keeps DELIMITER stretches as written.
- **N-249** — a leading UTF-8 BOM is outside every chunk.

**Crashes**

- **N-250** — completion's zero `tok` is no name (`tNone`); a leading `.`
  no longer panics (reproduced through the TUI's typing path).
- **N-258** — `sdb.S.Show` evens a hand-built result's rows; the grid reads
  past a short row as blank.
- **N-259** — the designer's import parser refuses past 500 levels of
  nesting instead of a fatal stack overflow that took dbc web down.
- **N-260** — every goroutine dbc web starts runs under `goSafe`/`runSafe`;
  a run's Job that panics is abandoned (`Workspace.AbandonRun`) so the tab
  is not busy for good.

**Pipelines (etl, pipeline)** — three commits, N-251, N-253, N-252

- **N-251** — `etl.ReadWith(…, ReadOptions{Hold: true})`; sql.read/sql.table
  read held, so the source commits after every sink.
- **N-253** — the same-database rules moved from `etl.Copy` into the Writer
  (`NewSameDatabaseWriter`, `sameDatabaseSetup`); the runner marks a source
  and sinks on one Postgres database. Unexported flags, as fields on

- **N-252** — a preview closes its source as failed (rolled back on

**TUI**

- **N-257** — quit (^C idle, ^Q) and a connection switch ask when a session
  may hold a transaction; ^Q/^C again quits; SIGHUP never asks.

**Files and history (userdata)**

  rewrites under a sidecar lock its appends share; leaked temps swept.
- **N-256** — the history loader reads past an over-long line and rewrites

**dbc web, the formatter, scripts, explain**
