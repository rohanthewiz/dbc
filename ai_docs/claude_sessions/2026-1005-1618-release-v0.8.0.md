## Local install

- The cats plugin `rohanthewiz.dbc` is **linked** to this checkout
  (`~/.config/cats/plugins/rohanthewiz.dbc` points to the repo), so the
  `dbc` on PATH (`~/.cats/bin/dbc`) is the checkout's `bin/dbc`. That binary
  was stale at 0.6.0: it is built only at link time or when someone rebuilds
  it. It was rebuilt at the `v0.8.0` commit with the plugin's own build
  command (`go build -o bin/dbc .`), and `dbc --version` now prints 0.8.0.
- `~/Applications/dbc.app` was at 0.7.0. `./mac-install.sh` (with CATS_*
  stripped) rebuilt and re-signed it, and its `Contents/Helpers/dbc` now
  reports 0.8.0. The app was open at the time. The script only warns about
  that and replaces nothing that is running, so the open window keeps 0.7.0
  until it is quit and reopened.
