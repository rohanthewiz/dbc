## N-171: ⤓ Download a dump in the browser

- **The premise did not hold.** The item said "streaming pg_dump's
  stdout as the response would do", but rweb holds every response body
  in memory (`ctx.Bytes`; even static files are `os.ReadFile`). Only SSE
  writes as it goes.
- **Decision.** Real streaming means changing rweb, which is your
  library with a release of its own, so that is yours to decide. Within
  dbc:
  - The dialog's new ⤓ Download (plain, custom, tar) writes the dump to a
    server temp file, as any dump runs, under a 128-bit token.
  - When it ends, the page holding the token navigates to
    `GET /api/v1/dump/file/:token`, served once and then removed. The
    browser saves it.
- **Bounds:**
  - over 512 MB the dump stays on the server, and the log says where;
  - a download nobody fetches is removed after 30 minutes;
  - every waiting one is removed at Shutdown.
