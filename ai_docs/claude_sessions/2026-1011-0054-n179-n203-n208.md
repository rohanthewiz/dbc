## Decisions

- **Env for scripts is a copy, not the real one.** `Unrestricted` would
  let one script's `Setenv` leak into dbc web's process: later scripts,
  DSN `${VAR}` expansion, child processes. Scripts gain no new reach,
  since `os/exec` was already available to them.
- **N-205: a runtime hint, not a Check warning.** Warning at check time
  would mean parsing table names out of every SQL and lookup query. The
  hint is added to any failure in that position rather than matched
  against each driver's "no such table" wording.
- **N-206: an id that names no record.** A script's pipeline run leaves no
  record, but a unique id is what a key needs, and its format matches the
  jobs engine's.
- **N-207 is SQLite only.** MySQL's `CREATE TABLE … SELECT` and Postgres's
  `CREATE TABLE AS` report real counts.
- **N-208's "paid received 4" was a misreading** caused by the node order,
  not a counting bug.
- The session-doc stem was picked before the doc was written. The Closed
  lines were re-stamped to this file's name.
