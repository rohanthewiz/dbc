# Web sidebar in-use mark: a short dash per row

Session: `16cb547e-a686-4182-8761-8a6b49df12f9`

## Ask

From the cats-todo backlog, next-list item N-100: the web sidebar's in-use
mark (`.conn-item.inuse`, a dimmed accent bar) is subtle, and on adjacent
rows the bars join into one line. Shorten each bar so rows read apart, or
add a small glyph. Then wrap the session and cut a minor release.

## Change: the in-use bar becomes a dash

`web/static/css/app.css`:

- `.conn-item` gets `position: relative`.
- `.conn-item.inuse` lost its full-height `box-shadow: inset 2px 0 …` and
  draws `.conn-item.inuse:not(.active)::before` instead: an absolutely placed
  2px-wide dash, `top: 4px; bottom: 4px`, rounded 1px, in the same dimmed
  accent (`color-mix(in srgb, var(--accent) 45%, transparent)`).

Why this shape:

- Inset 4px top and bottom, adjacent in-use rows show two dashes with an
  8px gap, not one joined line. The shorter shape also sets it apart from
  `.active`'s full-height bright bar, so the two marks differ in form as well
  as in brightness.
- A pseudo-element rather than a `background-image` gradient: `:hover` (and
  `.active`) set the `background` shorthand, which would wipe a gradient.
  `position: absolute` keeps it out of the flex row, so it does not sit
  between `.name` and `.driver`.
- `:not(.active)` keeps the old rule that the bright bar wins when a row is
  both (another tab is on the connection this tab is on).

No glyph was added; the dash was enough. `app.js` (`markInUse`) is unchanged.
Only the CSS changed.

```
  ┃ local-pg     .active: full height, bright
  ╷ reports      .inuse: shorter, dimmed, a gap
  ╵ analytics      between neighbouring rows
```
