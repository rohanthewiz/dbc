## N-177: pipeline and job drafts per window

Pipeline and job tabs kept one localStorage key per file
(`dbc.pipe.draft.<name>`, `dbc.job.draft.<name>`). Two windows with one
file open shared it, and the last to type won, as script drafts did
before N-135.

- **Shared, not ported.** The script kit's scheme moved whole into a new
  `drafts.js` (`dbc.drafts`), loaded before `scripts.js`. That is the
  owner id, the heartbeat, orphan adoption and orphan rename. One owner
  and one heartbeat serve every kit. Each kit asks
  `dbc.drafts.kit(prefix, log)` for `read`, `write`, `adopt` and
  `rename`.
- **Old drafts are not lost.** The prefixes stay as they were, so an
  older page's one-key draft is adopted as an orphan, as scripts' were.
- **What else moved with it:**
  - `forgetGone` now keeps an owner's heartbeat while that owner has a
    draft in any kit.
  - app.js's duplicated-tab path calls `dbc.drafts.newOwner`.
  - Pipeline and job tabs now say when another live window has unsaved
    edits of the file, as script tabs do.
- **Found on the way.** Both canvas kits had one draft timer for all
  files. An edit to a second file within 300 ms cancelled the first
  file's draft write. A pending timer could also write a draft back
  after Discard. Each file now has its own timer; `forget` clears it,
  and a close that keeps the edits writes the latest text at once.

## N-191: a copy whose Plugin.Name is taken is renamed

- **Decision: rename when needed, don't offer.** The item said the copy
  flows "could offer" to rename Name. Every caller of either UI's
  `makePlugin` makes a copy (an example, a duplicate, + New from an
  example), and a copy whose Name is taken never loads. So it is renamed
  when needed, and the log says so.
- **`script.FitPluginName(text, file, taken)`** rewrites only the
  `Name:` string literal of `var Plugin = sdb.Plugin{…}`, interpreted or
  raw. A computed Name, or text that does not parse, is written as is.
- **The new name** comes from `PluginNameFor`: the file's stem with its
  underscores as dots, the examples' own pairing (`mask_email.go` ↔
  `mask.email`). If that is taken too, it gets -2, -3….
- **What counts as taken** (`script.PluginNameTaken`): a built-in or
  loaded plugin, or a load problem's Name, since a broken file would take
  the name back once fixed. Both hosts sync the plugins before asking.
- **Wiring.** The TUI's `makePlugin` calls it. dbc web's plugin PUT takes
  `fit: true` on a create and answers `renamed: {from, to}`;
  `scripts.js` sends `fit`, logs the rename, and its name prompt no
  longer tells you to change Name by hand.
